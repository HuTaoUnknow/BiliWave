# BiliWave · 哔哩音频库

1.10.0 提供两个版本：**完整版**含字幕 OCR 与已有歌词配时；**Lite 在线歌词版**下载后直接入库，保留工作台，仅在线搜索和采用现成时间轴，不包含本机识别、模型对齐或歌词导入。两者都有乐库、歌单、播放、桌面歌词、自动消声、托盘与开机启动。见 [版本说明](docs/LITE.md) 和 [更新记录](CHANGELOG.md)。

在线歌词支持清理视频标题、多轮查询、去重及匹配度排序；“在线搜索”可填关键词或 LRCLIB 歌词链接，按 Enter 重新搜索。新版仍取决于 LRCLIB 的数据覆盖，不承诺所有歌曲都有歌词。

自动消声支持麦克风说话、其他应用开麦或发声，降低幅度可调。见 [自动消声](docs/AUTO_DUCKING.md)。

最新队列、顶部待播标记和歌曲导出操作见 [QUEUE_PROGRESS_EXPORT.md](docs/QUEUE_PROGRESS_EXPORT.md)。

中、英、俄三首真实歌曲的字幕识别、时间匹配结果与同源字幕校准操作见 [MUSIC_LYRICS_BENCHMARK.md](docs/MUSIC_LYRICS_BENCHMARK.md)。

Windows Qt 桌面应用：搜索并收藏哔哩哔哩原始音轨、管理多个歌单、播放本地与 URL 歌曲，并显示双句桌面歌词。1.9 版简化搜索和歌词操作，取消音频听写，增加逐句配时编辑与任务删除；仅保留已有歌词的对齐模型。队列重复项、排序和拖动图标见 `docs/QUEUE_OCCURRENCES.md`，字幕判据与空白修复见 `docs/OCR_COMPARISON_REVIEW.md`。下载任务入口、双语字幕与独立显示设置见 `docs/BILINGUAL_WORKBENCH.md`。当前界面操作见 `docs/UI_REFINEMENTS.md`，顶部条见 `docs/TOP_PROGRESS.md`，歌词流程见 `docs/LYRIC_QUEUE.md`。

## 直接运行

打开 `release/BiliWave.exe`。首次使用前可整体移动 `release` 文件夹；首次启动在同级 `data/` 下创建资料库。已有歌曲保存实际文件路径，迁移时须保留媒体路径或重新导入。

开发目录中也可运行 `scripts/run.ps1`。应用不依赖系统安装 Python，音频处理和本机识别组件均已随工程准备。

## 获取与播放

搜索三栏默认约 51% / 35% / 14%，手动拖动后保存并在下次打开恢复；小窗口按控件最小宽度调整。

1. 进入“搜索”，输入歌曲名称、HTTPS 哔哩哔哩链接、短链接、BV 或 av 号，点击“搜索”。结果列表展示封面、标题、时长和 UP 主。
2. 名称搜索显示第一页，可点击上一页、下一页。视频号会自动列出所有分 P；双击结果弹出 URL 收录、下载、取消选项，不展开分 P。
3. 点击结果右上“下载”保存原始音频。下载任务为较宽的卡片，下排依次为删除、收录、工作台三个简笔图标。下载完成后，点方形唱片“收录”直接导入乐库并移除任务；点“工作台”图标或双击任务才进入独立歌词工作台，不自动匹配。下载期间后两个按钮禁用；删除仅取消该任务。取消时移除任务并清理该任务生成的下载文件，失败保留。点击“URL 收录”只保存视频链接并直接入库，不进入工作台。工作台“导入乐库”等待可用时间轴歌词后入库；“不配置歌词导入乐库”立即收录，提示位于左侧导航下方。未入库的下载不显示于乐库。
4. 进入“乐库”，左侧显示歌曲和时长，右侧用与播放页一致的唱片卡片显示歌单。右击卡片可重命名、删除歌单。顶部筛选框点击确认或回车生效，取消清空筛选。列表右上排序按钮循环 A~Z / time（时长）/ size（文件大小），旁边箭头切换正序与逆序。也可导入本地音频，或从资源管理器拖文件到歌曲表。
5. 点击右侧歌单：左侧改为该歌单尚未收录的歌曲，右侧显示已收录歌曲。拖动歌曲或点击左下“收录选中 →”（Ctrl+A）添加；选择右侧歌曲后点击“← 从歌单移出”（Ctrl+D）仅删除关联。点击“← 返回歌单”或 Esc 恢复全部歌曲及歌单卡片。快捷键作用于乐库区域，顶部输入框仍可正常全选文字。
6. 乐库中的歌曲和歌单支持右击重命名与删除。同一首歌可以收录到多个歌单，仍在歌曲库中独立存在。在歌单内拖动歌曲可排序。乐库双击歌曲不启动播放。
7. 进入下方独立的“播放”页，左上“歌曲 / 歌单”互斥切换。歌曲显示歌名和时长；歌单显示方形唱片及右上方唱臂，名字位于下方。单击歌单进入相同的歌曲列表，点击返回回到歌单卡片。
8. 双击歌曲播放当前列表，或选中歌曲后加入右侧播放队列。歌曲和歌单可拖到右侧队列。右侧当前播放项固定在最下面，待播歌曲从下向上播放，只显示歌名。同一首歌可以多次加入，每次添加单独排序和移除；随机模式显示已确定的待播顺序，单曲循环仍可整理其他待播项。
9. 歌曲行右侧 → 加入队列。队列左侧为竖排置顶/置底、上移/下移，末尾 × 按钮移除单项；圆环叠音乐符号仅在该项正在播放时旋转。拖动歌曲显示小音乐图标。队列还支持双击立即播放、右击移除、清空；这些操作不删除乐库和歌单中的歌曲。播放控制支持顺序播放、列表循环、随机播放、单曲循环及进度跳转。悬浮条与桌面歌词开关位于左下设置上方，也可在设置里调整。

URL 歌曲显示 `[URL]`，每次播放重新解析可访问的高质量音轨，使用内存流式转发，不保存整首音频。URL 收录不会进入歌词工作台；歌词配置请先下载，再通过完成任务的工作台按钮进入。乐库右键仍可直接导入已有 LRC 或编辑、导出时间轴。

顶部进度条固定于主屏幕最顶端，铺满整个上边缘。红色为已播放，蓝色为未播放，交界平滑渐变并随进度移动；整条向下渐隐。没有按钮、文字或鼠标交互，点击穿透。设置可即时调整已播放颜色、未播放颜色、渐变宽度（0–4096 px，默认 80 px）与渐隐高度（1–512 实际屏幕像素，默认 24 px）。零进度全蓝，完成时全红。左下或设置中的开关控制显示。

## 音质与文件

优先选择当前可访问的 FLAC / ALAC 无损音轨，否则按音频流报告的码率选择高质量音轨。实际编码、码率、采样率和声道数据保存在资料库中。

哔哩哔哩 DASH 的原始音轨保留为 `*.source.m4s`，再使用 FFmpeg `-c:a copy` 输出播放文件：AAC / ALAC 对应 M4A，FLAC 对应 FLAC，Opus 对应 Opus，其他编码使用兼容容器。原始媒体不是 MP4 系列容器时，保留其真实扩展名。

乐库右键可导出歌曲及歌词，保留原音轨，同时写入歌词元数据和同名 UTF-8 LRC；URL 歌曲先获取音轨再导出。

默认不重新压缩、不转 MP3、不提高采样率。AAC 转成 FLAC 不能补回源音频已经丢失的细节。平台无损音轨不存在或当前账号不可访问时，应用不能创造该音质。

默认下载目录为 `data/media/`。文件名使用任务标识避免重名，歌曲表显示真实视频标题，可右键“编辑歌名 / 歌手”。右键可以打开文件目录或原视频。从歌单移除只删除关联；从歌曲库移除会删除所有歌单引用并保留磁盘文件；“删除歌曲及磁盘文件”会另行确认后删除播放文件及原轨。

## 歌词

俄语、意大利语字幕识别和已有歌词配时已支持。字幕预览可选择对应语言；配时原文审阅步骤及设置中同样有俄语、意大利语。模型、验证与操作见 [RUSSIAN_ITALIAN.md](docs/RUSSIAN_ITALIAN.md)。

字幕识别已增加 GPU 加速与“画面变化分段 → 中间帧 OCR → 相似文字合并”，不再逐采样帧完整识别。设置可选择自动优先 GPU、GPU、CPU；字幕范围窗口可调整变化阈值和合并相似度。实测及详细说明见 [GPU_OCR.md](docs/GPU_OCR.md)。

### 歌词方案与队列（1.9）

歌手下方有分隔线和“歌词匹配”标题，三个互斥按钮完整显示“线上匹配 / 本机识别 / 导入 LRC”。本机识别的识别字幕（默认优先）、导入歌词也以按钮显示。选项区高度固定，切换不挤动下方内容；时间轴歌词列表已加长。

1. 识别字幕自动使用歌曲源对应的分 P 视频，也可选择本地同版本视频。进入配置自动读取一帧预览，可点击“向后 15 s”更换画面。直接拖动绿框移动、拖边角缩放、框外拖出新区域，或输入左/右/上/下边距，双向实时同步；默认下三分之一。范围调整不重新请求视频。在线视频按需读取，不预先下载整段；打开其他方案不会请求视频。FFmpeg 先裁剪、抽帧，RapidOCR 只接收裁剪后的图像。根据字幕出现时间生成 LRC，上一句持续显示至下一句；不再写入空白时间点，重复副歌仍保留。原始字幕消失时间另存于识别诊断结果。
2. 音频听写及其 ggml 模型已移除。导入歌词可先使用固定模板询问 DeepSeek：按钮复制模板并打开网页，由使用者提交并将回复粘贴回来，或导入 TXT；使用现成文字通过 stable-ts 匹配本地音频，保留原文。导入 TXT / LRC / SRT 或粘贴文字后，可逐行检查、选择语言。已有 LRC 可直接使用原时间轴。
3. 线上查询 LRCLIB 的时间轴及纯文本候选。纯文本或翻唱版本可使用候选文字重新匹配音频。线上没有合适结果时可手动切换本机方案，不静默启动听写。
4. 结果可编辑 LRC、应用后试听并调整同步偏移。识别按钮后显示旋转加载图标。
5. 点击开始识别或按音频匹配时间后，关闭配置窗口并回到主工作台，任务在右侧后台执行。队列依次执行，支持叉号或 Del 删除，取消自动移除，失败重试、查看和应用；下方固定进度条显示当前运行任务的阶段和百分比，选择其他任务也能查看当前进度。完成后先保留为“待应用”，切换歌曲不会改变任务归属或覆盖原歌词。退出程序会停止任务，当前队列不跨重启恢复。

字幕 OCR 支持中英、俄语、意大利语，以及英汉、俄汉、意汉双语，时间精度受采样间隔影响（默认 0.5 秒，最低 0.1 秒）。请使用同源同分 P 视频；水印、多行字幕、逐字高亮和字幕提前显示可能需要修正及试听。音频对齐仍可能在间奏、拖长音或错版歌词处偏移。原音乐不修改、不重新编码。完整操作见 `docs/LYRIC_QUEUE.md`。

当前工程和发布包已带独立 Python、CPU 推理库、OCR 模型及对齐模型，无需另装系统 Python。首次重新准备这些依赖可运行 `scripts/setup-lyric-tools.ps1`；设置中可修改对齐模型和歌词工具环境路径。

### 在线时间轴与编辑

左侧导航在“播放”下面提供独立“工作台”，内含歌词配置与识别队列；搜索页左侧为结果，右侧为下载任务。仅由下载完成任务的双击或工作台按钮把歌曲送入工作台；下拉框只切换已经这样打开过的本地歌曲。单击搜索结果、URL 收录和下载完成均不自动切换工作台，也不自动匹配。切回搜索或播放时，后台识别继续执行。默认来源可选择线上匹配、本机识别、导入 LRC。

工作台可修正歌名和歌手，首次点击“线上匹配”检索，已有候选后再次点击依次采用后面的候选，不循环回第一个；修改歌名或歌手后重新检索。低可信度结果在同一页面显示候选、时长差及歌词预览；点击“采用候选并试听”保存并播放，调整同步偏移检查匹配程度。可随时改用其他来源、“本机识别”或“导入 LRC”。双击已采用歌词可跳转。工作台底部靠右为较小的试听按钮和识别字幕按钮；识别任务在右侧队列取消或删除。仍可通过右键编辑及导出 LRC。

- 在线自动采用要求歌名、歌手匹配且时长接近。其他结果会列出候选、时长差及预览，避免悄悄套用错误版本。视频标题包含封面文案或演唱者缺失时，可先编辑歌名与歌手再匹配；上传者不会被误当成歌手。
- 本地 LRC 请使用 UTF-8 编码。导入本地歌曲时会尝试读取同名 `.lrc`。
- 时间轴列表每行右侧 ▴ / ▾ 提前或延后 100 ms，× 直接删除该行文字和时间；右击可在下一行添加歌词，默认时间取前后两行中间。其他行的时间不因删除而改变。
- 桌面歌词为纯色，无黑边。双语歌词外语左上、中文右下，单语显示当前句和下一句。两行各自的字号、透明度、颜色以及水平、垂直位差均可设置，另有识别语言、锁定位置和鼠标穿透选项。
- 每首歌曲在歌词工作台独立保存时间偏移；正值表示歌词提前显示。试听时可实时调整。跳转、暂停、切歌均使用播放器时间重新定位。
- 没有时间轴时显示歌曲名及提示，不伪造同步歌词。

在线检索发送歌名、歌手等元数据；本机识别不上传音频。无需付费 API Key。

## 登录与资源设置

设置顶部按“通用设置、进度条、歌词显示、资源与工具保存”分组，右侧留弹性空白；分类按钮与底部保存按钮固定，内容分别滚动。字幕计算方式、默认歌词来源和语言使用横排互斥复选框，滚轮不会切换这些选项。切换分类保留未保存的编辑，点击“保存设置”统一保存。详见 [SETTINGS_WORKBENCH.md](docs/SETTINGS_WORKBENCH.md)。

通用设置增加“深色蓝色 / 浅粉玫瑰”主题，点击立即换肤并记住选择。主界面、唱片卡片、队列与歌词操作弹窗统一配色，工作台底部操作固定可见；识别结果可逐句编辑或切换到 LRC 文本。设计对应与截图见 [UI_THEMES.md](docs/UI_THEMES.md)。主题不改写桌面歌词与顶部条的独立显示设置。

乐库右键支持“删除歌曲及相关文件…”，确认后清理所选歌曲的播放文件、原音轨、旁存歌词/封面、应用 UUID 关联文件与歌曲记录、识别任务；共享资源保留，失败时保留相关歌曲记录。下载卡片和字幕窗口的最新操作见 [DOWNLOAD_CARDS_AND_DELETE.md](docs/DOWNLOAD_CARDS_AND_DELETE.md)。

设置 → 资源与工具保存可修改下载目录、yt-dlp、FFmpeg、ffprobe、歌词对齐模型和 Python 工具环境路径。可选择本机 Netscape 格式 Cookie 文件访问已获授权的资源；不需要将账号密码或 Cookie 内容发给开发者。最高可用音质受账号权限、地区及源文件限制。登录音轨尚需使用者在本机配置后验收。

Cookie 文件只保存路径。不要将 Cookie 文件放进源码提交或随发布包分享。应用不会自动读取浏览器登录资料。

## 构建与部署

已验证环境：Qt 6.11.1 MinGW 64 位、GCC 13.1.0、CMake 3.30.5、Ninja。当前 Qt 位于 `D:/PC/EXE/QtCreator/6.11.1/mingw_64`，Qt Creator 中遗留的 `D:/PC/EXE/Qt/...` 路径需要改为此路径。

```powershell
# 已有依赖的当前工程
./scripts/build.ps1 -Deploy

# 重新获取音频下载、处理依赖
./scripts/setup-dependencies.ps1

# 准备已有歌词时间对齐及视频 OCR 依赖
./scripts/setup-lyric-tools.ps1

# 从开发目录启动
./scripts/run.ps1
```

工具链路径可使用 `-QtRoot`、`-QtTools` 参数修改。Qt Creator 直接打开 `CMakeLists.txt`，选择现有 Qt 6.11.1 MinGW Kit。所需模块为 Widgets、Multimedia、Network、Sql 和 Test。

`build.ps1` 完成编译、核心测试及原生 Windows 集成测试。`-Deploy` 用 windeployqt 收集 Qt、编译器运行库、平台及媒体插件，然后复制工具、模型、说明与许可文件到 `release/`。Qt 播放后端随 Qt 使用 FFmpeg 7.1.3；音频处理命令使用独立的 FFmpeg 9.0.2，两者不互相替换 DLL。

目录：`src/` 应用，`tests/` 测试，`scripts/` 构建及依赖准备，`tools/` 可执行依赖，`models/` 离线模型，`docs/` 验证证据及许可，`data/` 开发运行资料库，`release/` 便携版本。

## 验证与限制
