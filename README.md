# BiliWave · 音乐工作台

面向 Windows 的 Qt 桌面音频库，支持哔哩哔哩搜索、原轨下载、URL 收藏、多歌单、播放队列和时间轴歌词。本文描述当前工程；公开安装包的功能以对应 GitHub Release 说明为准。

## 两个版本

| 能力 | 加装版 | 简装版 Lite |
| --- | --- | --- |
| 搜索、下载原轨、URL 收藏、本地导入 | 支持 | 支持 |
| 乐库、多歌单、重复入队、桌面歌词 | 支持 | 支持 |
| 独立工作台、现成歌词在线匹配、整体偏移、歌词裁剪 | 支持 | 支持 |
| 字幕区域选择、当前帧校验、视频字幕 OCR、GPU | 支持 | 不包含 |
| 导入 / 编辑时间轴及本机歌词处理入口 | 支持 | 仅保留线上匹配功能 |
| Whisper、音频听写、音频对齐模型 | 不打包 | 不打包 |

## 使用流程

1. 搜索歌曲名称、视频号或视频链接，查看封面、标题、时长、UP 主；名称搜索支持分页，视频号一次列出分 P。
2. 双击或回车选择 URL 收录、下载、取消。URL 与下载都进入右侧收录队列，可直接收录，或送到工作台配置歌词。
3. 工作台按歌曲保存独立草稿。线上 / 本机结果先进入识别队列，标记编号和来源；查看、应用后可试听、调整整体偏移和裁剪时间轴。歌词应用不改歌名、歌手，也不覆盖其他歌曲草稿。导入或保存到乐库后清空当前工作台。
4. 乐库中一首歌曲可以加入多个歌单。支持筛选无归属歌曲、排序、重命名、删除，以及导出音轨和歌词；删除文件使用单独的确认操作。
5. 播放页浏览歌曲或歌单。进入歌单后提供顺序 / 随机追加整张歌单的按钮；歌单卡片只显示唱片、名称和总时长。
6. 队列从底部向上排列，当前歌曲在最底部，同一首歌可多次入队。播完移除，不自动重新添加；可移动、删除或清空队列。

播放模式只有 **顺序播放、随机播放、单曲循环**。原“列表播放”已合并进顺序播放，旧配置可继续读取。无歌词、无歌曲或停止播放时，歌词显示区域保持空白。

## 按键与本地导入

搜索页 Ctrl+F 定位搜索框，回车搜索后聚焦首条结果；结果中上下选歌、左右翻页、回车打开收录弹窗。Tab 按“搜索结果 → 收录队列 → 底部播放按钮 → 搜索框”循环。队列内上下切换项目、左右选择删除 / 收录 / 工作台、回车确认。

窗口启动或重新激活时默认聚焦播放 / 暂停按钮。该按钮上回车切换播放、上下按音量分段调整（10 / 5 / 1 个百分点）、左右调用上一首 / 下一首。乐库、播放页和工作台不额外增加页面快捷键，原有操作保留。

本地音频可拖到窗口或桌面快捷方式。散文件直接加入“导入”歌单；文件夹的第一层音频加入同名歌单，发现子文件夹会提示并跳过。不自动配置歌词、不移动原文件。详见 [键盘与导入](docs/KEYBOARD_AND_LOCAL_IMPORT.md)。

## 歌词与音质

在线歌词提供塞壬官方、网易云、QQ、LRCLIB、酷狗、Lyrics.ovh。优先源无结果时才查备用源，每批最多 5 个候选；点击继续搜索获取下一批。请求串行、缓存优先、至少间隔 1 秒，每次点击最多 8 个请求；遇限流停止，不自动重试。[在线歌词说明](docs/ONLINE_LYRIC_SOURCES.md)

加装版字幕 OCR 先裁剪用户选定区域，再通过画面变化分段，只对代表帧识别；相似文字按百分比合并，空白时段沿用上一句。支持中、英、俄、意等语言及双语。字幕语言、空格间距敏感度、当前帧识别可在框选窗口校验。两版均不提供音频模型自动配时。

双语使用同一条有序播放轴：外语左上、中文右下，时间戳相同同时更新，不同则分别更新。繁体自动转简体默认开启，保留原文与时间戳。歌词剪裁只改工作台时间轴，不裁剪音频。[时间轴裁剪](docs/TIMELINE_TRIM.md)

下载优先选择可访问的 FLAC / ALAC，否则选择高质量音轨。DASH 原轨保留为 `*.source.m4s`，播放文件由 FFmpeg 直接封装（`-c:a copy`），不提高采样率、不重新有损压缩。URL 歌曲每次播放解析可访问音轨并流式播放。

## 外观与系统

通用设置提供 **大肥鱼、ChatGPT、Grok、Claude、浅粉玫瑰** 五种主题；点击立即应用并保存。主题影响导航、按钮、列表、图标与弹窗，不覆盖用户设置的桌面歌词或顶部条颜色。[主题目录](docs/UI_THEMES.md)

顶部进度条铺满主屏幕上沿，显示当前歌曲进度与最多 10 个待播短点，点击穿透。颜色、渐变宽度、向下渐隐高度和短点长度可调。桌面歌词的字号、透明度、颜色、位差可分别设置。

默认跟随系统音频输出，支持耳机热插拔、手动选择与重新检测。自动消声可按麦克风说话、其他应用开麦或发声降低音乐音量。关闭到托盘与开机自启动可在通用设置开启。

## 工程与构建

当前本机 Qt 6.11.1 / MinGW 13.1；工程使用 C++17、CMake、Ninja、Qt Widgets / Multimedia / Network / Sql。源码结构及本轮整理记录见 [PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md)。

```powershell
# 加装版：编译、测试；-Deploy 可更新 release-screen
./scripts/build.ps1
# 简装版：编译、测试并更新 release-lite
./scripts/build-lite.ps1
# Debug
./scripts/build-debug.ps1
```

当前本地程序分别位于 `release-screen/BiliWave.exe`、`release-lite/BiliWave.exe`、`build-debug/BiliWave.exe`。首次启动在所选数据目录建立 SQLite 和设置；原有乐库继续使用，移动目录时需保留媒体路径。

后续安装包会检测本版已有安装，先选择覆盖升级或单独安装。覆盖保留原乐库和设置；单独安装使用独立目录、快捷方式和卸载项。详见 [安装与升级](docs/INSTALL_UPGRADE.md)。

编译按 `bili_core → bili_services → bili_ui → 应用 / 测试` 分层，UI 实现只编译一次供多个目标复用。`tests/` 包含核心、在线源、本地媒体、主题、工作台、设备与 OCR 验证；外网实测单独开启，常规测试使用隔离数据和本地服务。

`data/`、下载音频、歌词、缓存、Cookie、工具和模型不提交到公开仓库。第三方说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)；历史行为与安装包验证见 [CHANGELOG.md](CHANGELOG.md)、[docs/VALIDATION.md](docs/VALIDATION.md)。
