# 歌曲拖动与播放队列（2026-10-22）

乐库和播放页拖动歌曲时显示小型薄荷绿音乐符号。多选时附带数量；拖动仍采用原有歌曲数据，乐库的多歌单关联保持不变。

每次加入队列都有独立条目标识，同一首歌可反复加入。单个条目的移动、移除、双击播放及上一首历史都按条目标识操作。连续播放同一首歌会从头重新播放；恢复队列时保留重复项和当前条目的位置。

右侧队列不显示时长；正在播放的条目固定在最下面，待播歌曲从下向上播放。左侧第一组竖排置顶/置底，第二组竖排上移/下移：置底是排到下一首，置顶是移到待播队列最后。当前条目已固定，其位置按钮禁用。名字右边为圆环叠音乐符号，实际播放时转动，暂停和隐藏页面时停止；最后的拔插按钮只移除这一项。右击也可移除，双击可立即播放该次添加的歌曲。

顺序、列表循环、随机和单曲循环仍可使用。随机模式的排序操作会改变已经确定的待播次序。单曲循环时仍显示其他待播歌曲，便于整理；自动结束继续重复当前歌曲，手动下一首可切换。

播放队列使用从标题下方延伸到底部的固定列表区域，空队列也保留相同高度。移除待播数量、播放模式、播放顺序说明和上下弹簧，不再按照条目数量改变列表高度。
