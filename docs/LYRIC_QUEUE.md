# BiliWave 1.9 歌词识别与队列

歌手下方的“歌词匹配”分为线上匹配、本机识别、导入 LRC。线上匹配查询 LRCLIB，严格匹配的已有时间轴可直接使用，其他版本列出候选。没有找到时可手动切换方案；不再静默启动音频听写。

歌手下有分隔线，“歌词匹配”标题下方完整显示三个互斥切换按钮。本机的识别字幕、导入歌词也使用互斥按钮。选项区固定高度，切换来源或本机选项不改变下方布局；时间轴歌词列表加长，可显示更多行。

本机识别默认选择“识别字幕”，另有“导入歌词”。

- 识别字幕：自动填入歌曲来源的视频链接（保留分 P），也可选择同版本本地视频。进入字幕配置后自动读取一帧，显示绿色截取框；“向后 15 s”更换预览画面，超出片尾会循环到开头。可在预览画面内拖动绿框、拖拽边角缩放，或在框外拖出新区域；左、右、上、下边距输入与绿框实时同步。边距按整幅画面百分比计算，默认左 0%、右 0%、上 66.6667%、下 0%。调整范围只重绘当前画面，不重新请求视频。仅打开其他歌词方案时不会请求视频。在线视频只解析流地址，预览按需读取单帧，不先下载完整视频；开始识别后 FFmpeg 流式抽帧、裁剪，将小区域直接传给 RapidOCR，避免保存完整影片或大量截图。合并连续相同字幕，保留跨间隔重复的副歌，使用每句出现和消失时间生成 LRC，字幕空白期间清空歌词。此方案不依赖本地音频，URL 歌曲也能使用。
- 导入歌词：先显示 DeepSeek 提问模板，按钮复制并打开网页，由使用者提交；收到歌词后导入或粘贴 TXT、LRC、SRT 后检查逐行歌词，用 stable-ts 按当前本地音频重新匹配时间，保留现成文字。需要按实际演唱顺序填写重复副歌。已有 LRC 可选择直接使用时间轴。

“导入 LRC”大项直接载入有效 UTF-8 时间轴歌词，保留原时间。

点击开始识别或按音频匹配时间后，配置窗口立即关闭并回到主工作台，任务在最右侧队列继续运行；不最小化主窗口。完成后通过队列“查看 / 应用”检查、编辑歌词。已有识别队列时，新提交的任务顺序执行。队列只处理歌词，不影响试听、播放、搜索和下载。


任务可取消、失败重试、查看和应用结果。取消后自动删除；每行右侧 × 或选中按 Del 可删除任意任务，删除运行任务会同时停止该任务。队列完成后标为“待应用”，查看时可编辑 LRC，再保存到该任务原来的歌曲；不会因当前选中其他歌曲而覆盖它。取消或失败保留原歌词。若提交以后原歌词有更新，应用窗口会提示。识别按钮后显示旋转加载图标，队列显示阶段、进度及结果状态。

队列保存在当前进程内；退出应用会停止任务，重启后不自动恢复。字幕时间精度受采样间隔影响，默认 0.5 秒，可调至 0.1 秒。字幕提前显示、字幕版本不同、逐字高亮、水印和多语种同屏可能需要调整范围、修正文字并试听；本机 OCR 主要支持中英文。歌曲音频与同源视频存在剪辑偏移时，可在工作台调整同步偏移。

所有识别组件沿用项目内置环境，无需额外资源。源音乐不会被重新编码或修改。

2026-10-23 起，工作台及识别队列移到左侧“播放”下面的独立工作台页，搜索结果和下载任务留在搜索页。新工作台两栏默认 75% / 25%，拖动分栏后自动保存，下次恢复；窄窗口仍保证控件最小宽度。原搜索页三栏设置保留但不再使用。

队列下方固定显示当前运行任务的进度条与阶段，选择等待、取消或已完成的其他任务不会切换掉正在运行任务的进度。字幕识别按已处理的视频位置更新进度；准备阶段可能短暂显示不定进度，完成显示 100%。

音频听写功能、whisper-cli 和 ggml-small.bin 已移除；保留 small.pt 仅用于把已有文字对齐到音频。工作台每行歌词可提前/延后 100 ms、删除；右击可在下方添加。删除同时移除该行文字和时间，其他行保持时间。桌面歌词使用单一颜色、无描边。线上候选首次检索后重复点击“线上匹配”依次查看并采用后面的版本。
