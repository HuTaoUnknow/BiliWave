# 搜索键盘操作与本地拖入

主窗口启动或重新激活时，焦点默认位于底部播放 / 暂停按钮。该按钮聚焦后，回车切换播放 / 暂停，← / → 调用上一首 / 下一首，↑ / ↓ 调整音量。音量在 20% 以上按 10 个百分点变化，5% 到 20% 按 5 个百分点变化，5% 以下按 1 个百分点变化；跨段时停在边界，例如向下调整为 25→20→15、6→5→4。播放模式框仍通过原有鼠标或原生控件操作选择。

搜索页的按键顺序如下；乐库、播放页和工作台没有新增页面快捷键，原有操作保留。

| 焦点区域 | 按键 | 操作 |
| --- | --- | --- |
| 搜索页任意位置 | Ctrl+F | 聚焦搜索框并选中文字 |
| 搜索框 | 回车 | 搜索，返回结果后选中并聚焦第一首 |
| 搜索框 | Tab | 进入已有搜索结果；没有结果时进入收录队列 |
| 搜索结果 | ↑ / ↓ | 选择上一首 / 下一首 |
| 搜索结果 | ← / → | 上一页 / 下一页；不可翻页时保持原处 |
| 搜索结果 | 回车 | 打开 URL 收录、下载、取消弹窗；默认聚焦 URL 收录，Tab 切换选项，回车确认 |
| 搜索结果 | Tab | 进入收录队列 |
| 收录队列 | ↑ / ↓ | 切换项目，保持当前操作列 |
| 收录队列 | ← / → | 在删除、收录到乐库、工作台之间切换；跳过未就绪的操作 |
| 收录队列 | 回车 | 执行当前操作，删除或收录后保持在队列中 |
| 收录队列 | Tab | 聚焦底部播放 / 暂停按钮 |
| 底部播放 / 暂停按钮（搜索页） | Tab | 返回搜索框 |

关闭收录弹窗后回到原搜索结果。搜索请求结束时，仅在焦点仍处于搜索框或结果区域时转到首条结果；不抢走其他区域的焦点。空结果、空队列也能用 Tab 继续切换。

把本地音频拖到主窗口任意区域，或拖到应用的桌面快捷方式，直接导入乐库，不配置歌词、不读取同名 LRC。散文件加入“导入”歌单；文件夹中的第一层音频加入以文件夹名命名的歌单。同名歌单沿用，歌曲关联不重复；已存在歌曲的歌词与草稿保留。歌单在第一首音频成功导入时才创建。

文件夹不递归扫描。检测到子文件夹会显示提示，子文件夹内容跳过。支持 m4s、m4a、flac、mp3、wav、wave、opus、ogg、oga、aac、alac、mp4、mka、wma、ape、aif、aiff；最终仍由 ffprobe 确认实际音频轨道。导入保留原文件，不移动或删除源文件。

桌面快捷方式使用常规位置参数接收一个或多个文件 / 文件夹；已有应用实例时通过原单实例通道转交。相对路径在启动端转换为绝对路径，避免当前目录不同导致找不到文件。原 `--import`、`--search` 命令接口保留。
