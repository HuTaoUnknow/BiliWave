# 队列、顶部待播标记与歌曲导出（2026-10-22）

本次界面调整：下载完成任务的右箭头左边增加 ×，可删除待入库任务和该任务生成的音轨、封装及临时文件，同时取消关联歌词任务；导入的本地原文件保留。播放队列的置顶、置底与移除按钮采用和上下移动相同的黑底白色样式。左侧搜索、乐库、播放与设置使用统一尺寸矢量图标和相同字体，图标与文字分别对齐。

Windows 乐库拖动改用应用内音符提示，隐藏原生拖放禁止光标，仅显示音符；支持拖入歌单、歌单内排序和加入播放队列，Esc 可取消。功能测试覆盖这些操作以及删除下载任务时清理生成文件、保留本地源文件。

歌词工作台移动的是原有“匹配”操作按钮本身：现在位于底部试听按钮右边，随线上匹配、本机识别、导入 LRC 及本机方法切换文字。此前额外创建的识别字幕按钮已经移除，选项按钮仍用于选择方案。

播放队列：

- 播放完成或手动下一首消耗当前这一项，从队列删除，不返回队列；所有待播项播完后停止。显式的单曲循环模式继续循环当前项，手动下一首退出该项。
- 同一歌曲的多次添加仍是不同条目，互不影响；删除队列项不删除乐库歌曲。上一首不会将已消耗歌曲重新塞回队列，没有可回到的待播历史时回到当前歌曲开头。
- 队列区域默认宽度增加 50%，范围由 320–460 改为 480–690。置顶、置底使用箭头加横杠的矢量图标；其右侧是上下移动，再右侧为旋转音乐符号、歌名，末尾 × 移除。
- 播放页顶部“加入队列”按钮移除，保留逐行箭头、拖放及右键加入。

顶部进度条：红蓝部分只按当前歌曲的播放位置/时长计算。右端为待播项目绘制分离短点，包含同一歌曲的重复添加，默认白色、长度 10 个实际屏幕像素、间隔 4 像素，最多 10 个；多余项目不显示。短点与主条一起向下渐隐。短点颜色、长度（1–128 px）和显示上限（0–10）可在设置即时调整；0 个表示隐藏。短点占用条带右端空间，红蓝部分在剩余长度内显示当前歌曲完整进度。屏幕较窄、长度过大时减少可显示点数，给当前歌曲保留至少一半屏幕宽度。

下载任务入库后移除完成行；待入库完成任务仍显示右箭头。取消下载时终止任务进程树，清理该任务标识对应的原始音轨、封装输出、`.part`、`.ytdl` 和分片文件。清理限制于任务输出目录和 UUID 前缀，不删除导入的本地源文件或其他歌曲。

乐库歌曲右键“导出歌曲及歌词…”：

1. 选择导出文件名，沿用原音频格式。已有歌词的歌曲可导出；未配置歌词时会提示先配置。
2. 使用 FFmpeg 复制音频流，不重新编码；把歌词写入音频 `lyrics` 元数据，并生成同名 UTF-8 LRC 文件。
3. 单首歌曲的同步偏移会换算到导出 LRC 的时间点，双语文字保留共享时间点；用户乐库的原歌词不改变。
4. URL 歌曲先复用下载流程获取可访问音轨，使用独立临时资料库，之后按同样方式导出，不改变原 URL 歌曲或额外向乐库添加本地歌曲。
5. 目标歌曲或同名 LRC 已存在时提示更换名称，避免覆盖。导出临时目录自动清理。

验证：原生 Qt 测试实际播放到结尾，确认重复歌曲逐项消耗、最后停止且乐库仍保留歌曲；像素检查确认短点颜色、长度、最多十个及当前歌曲进度；取消下载测试确认清理任务产物、保留其他文件和本地源文件；FLAC/AAC 导出测试检查内嵌歌词、同名双语 LRC、偏移，以及导出前后音频流 SHA-256 完全一致。URL 导出测试使用受控下载工具验证临时资料库隔离，不替代真实网站网络可访问性测试。
