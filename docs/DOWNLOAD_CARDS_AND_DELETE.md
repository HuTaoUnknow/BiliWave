# 下载卡片、字幕参数与文件删除（2026-10-23）

下载栏加宽，各任务使用较高卡片。标题、状态下方一排三个图标：删除（叉号）、直接收录（方形唱片）、工作台（与左侧工作台导航相同的线条图标）。所有图标采用相同尺寸和线宽，跟随深色/粉色主题。未完成时禁用收录与工作台；单项删除只取消该下载，保留其他任务。完成后直接收录会入库并移除任务；工作台按钮和双击仍进入歌词配置。

字幕范围窗口：预览图下面第一行靠右为预览位置、向后 15 s；裁剪边距在下一行；采样间隔、画面变化阈值、文字合并相似度在同一行；字幕语言位于最下面。

乐库右键“删除歌曲及相关文件…”支持选中的一首或多首歌曲。确认框提供文件数量和完整路径详情，确认后才删除。清理范围：

- 歌曲记录所关联的播放文件和原始音轨。
- 同目录同名的 LRC、SRT、VTT、ASS、`.lyrics.txt`、封面和 JSON 旁存文件。
- 以应用生成的同一 UUID 命名的其他关联文件，包括尚存的下载碎片。
- 歌曲库内的歌词、歌单收录、播放队列项、工作台候选和该歌曲的识别任务。

仍被未选中歌曲使用的文件在确认框中单独列出并保留。文件被占用时先释放当前播放器、取消相关识别，再尝试删除并短暂重试；若仍失败，保留相关歌曲记录并显示失败路径。“从歌曲库移除（保留文件）”仍单独提供。

验证：界面回归覆盖三按钮位置、直接收录不跳页、禁用状态和删除失败任务；导入集成测试验证单项取消等待任务不会停止当前下载、当前任务取消清理自身文件。文件删除用独立临时目录中的真实 AAC 音轨验证取消确认、正在载入的音轨删除、原音轨/歌词/封面/碎片清理、队列和歌单移除、同目录其他文件及共享原文件保护。所有删除测试仅操作临时测试数据。
