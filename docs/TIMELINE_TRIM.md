# 工作台时间轴歌词裁剪

裁剪控件独占上方一行，依次放置裁剪秒数输入框及四个按钮；下方一行是“进度”、秒数输入框和左右箭头，试听与识别按钮靠右。默认裁剪 1 秒，可设为 0.1～3600 秒，并记住上次输入。窗口较窄时每行内的控件自动换行，裁剪始终位于进度上方。

先试听所选歌曲并定位到要处理的位置。只有当前播放器加载的歌曲与工作台所选歌曲相同、可定位且存在时间轴歌词时，裁剪按钮才启用。加装版、简装版及 URL 歌曲的试听均使用相同规则。

记当前试听进度为 `P`、整体偏移为 `O`、裁剪时长为 `D`，则歌词时钟位置 `T = P + O`：

| 按钮 | 删除的歌词时间点 |
| --- | --- |
| 裁剪后方 | `T ≤ 时间 < T + D` |
| 裁剪前方 | `T − D ≤ 时间 < T` |
| 向前裁剪至开头 | `时间 < T` |
| 向后裁剪至结束 | `时间 ≥ T` |

删除作用于时间点，双语同时间戳的原文与译文一起删除。其余时间戳、繁体原文、歌词来源和整体偏移保留；不会拼接或压缩时间轴，也不会修改音频文件、试听位置或播放状态。若区间内没有歌词，则不写入草稿。

裁剪先原子保存到该歌曲的工作台草稿，点击“保存”或“导入乐库”后才更新乐库歌词。其他歌曲的草稿及已经保存的乐库版本保持独立。
