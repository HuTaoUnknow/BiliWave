# BiliWave 1.1 界面重整

黑色主背景，左侧“搜索、播放”固定导航，“设置”位于底部。Release 与 Debug 已更新，桌面 `BiliWave Debug.lnk` 继续指向 `build-debug/BiliWave.exe`。

## 搜索

输入名称显示第一页视频，可上下翻页；输入 BV / av / 视频链接自动展开全部分 P。结果使用列表展示封面、标题、时长及分 P，选中下载保留原始音轨。双击名称结果可展开其分 P。

实际网络验证：

- 名称“音乐”第一页 20 条、第二页 20 条，页码和下一页标志正常。见 [第一页](search-live-page1.json)、[第二页](search-live-page2.json)。
- `BV1bK411W797` 返回 23 个分 P，P1、P2、P3 的独立标题、时长和带 `?p=` 的下载地址正确。见 [分 P 结果](search-live-parts.json)。
- `BV13x41117TL` 单视频信息正常。见 [单视频结果](search-live-video.json)。
- 更新后的 Debug 程序使用随包 Qt DLL，在清除开发 Qt 环境变量后正常启动，完成在线检索并加载实际封面。

![真实分 P 检索与封面](screenshots/live-search/library.png)

## 播放

初始左侧显示全部歌曲，右侧显示歌单。进入歌单后，左侧为未收录歌曲，右侧为已收录歌曲；返回恢复完整歌曲库。支持拖入收录、移出关联、歌单内排序、歌曲与歌单右键重命名及删除。整个歌单仍可从初始列表拖到悬浮条。

![歌单初始页](screenshots/playback.png)

![歌单内外分栏](screenshots/playlist-detail.png)

## 歌词与设置

搜索页歌词工作台支持选择已有歌曲，按默认来源匹配、预览候选、采用候选后试听、调整每首歌的时间偏移，或改用在线、本机识别、本地 LRC。设置页提供默认来源、透明度、字体、颜色、锁定、鼠标穿透和资源路径。
