# 设置分组与独立工作台（2026-10-23）

左侧导航依次为搜索、乐库、播放、工作台，设置位于底部。工作台沿用同尺寸图标和字体。

- 搜索页仅保留歌曲搜索、结果分页、URL 收录和下载任务。
- 下载完成后双击任务或点击右箭头，歌曲进入独立工作台并切换到该页；URL 收录直接入库，不打开工作台。
- 工作台含歌词配置和右侧识别队列，默认宽度比例 75% / 25%，拖动分栏自动保存。原搜索页三栏比例不再用于新页面。
- 页面切换不停止识别，任务完成仍等待检查和应用，不直接覆盖歌曲歌词。
- 原设置页面索引自动迁移，旧资料库继续使用。

设置顶部五个互斥按钮靠左，右侧为弹簧；分类内容独立滚动，按钮和保存操作固定。

| 分类 | 内容 |
| --- | --- |
| 通用设置 | 繁简转换、托盘与自启动；以分割线区分自动消音、主题、音频输出 |
| 工作台设置 | 在线词源与备用源、默认获取来源、字幕识别计算、默认字幕语言、切歌自动获取；简装版仅显示支持的线上功能 |
| 进度条 | 开关、红蓝颜色、待播短点、渐变宽度和渐隐高度 |
| 歌词显示 | 开关、两行字号/透明度/颜色、水平与垂直位差、锁定和鼠标穿透 |
| 资源与工具保存 | 音频目录、Cookie、yt-dlp、FFmpeg、ffprobe、对齐模型和 Python 环境 |

通用设置的枚举选项改为横排复选框，每组只能选一项；滚轮不更改选择。跨分类编辑保留，点击底部“保存设置”统一写入；进度条原有即时设置继续即时生效。

验证：四组 CTest 通过。专项覆盖真实点击与滚轮事件、互斥、跨分类保存及恢复、旧导航迁移、下载箭头切页、后台任务在搜索页继续完成、工作台比例拖动与恢复。
