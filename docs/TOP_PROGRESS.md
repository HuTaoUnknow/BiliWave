# BiliWave 1.7 顶部纯进度条

- 固定于主屏幕完整几何区域的最顶端，横跨全宽，不读取旧悬浮条位置。
- 完整铺满上边缘；已播放部分为红色（#ff3355），未播放部分为蓝色（#327dff），红蓝交界平滑渐变，中心随播放进度移动。整条向下渐变到透明。
- 无文字、按钮、滑块、拖动、拖放或点击响应；窗口始终置顶，不接受焦点，鼠标输入穿透。
- 设置 → 顶部进度条，可设置“已播放颜色”“未播放颜色”，以及向下渐隐高度。默认 24 px，范围 1–512 实际屏幕像素，在高 DPI 屏幕上换算窗口高度。更改即时生效并保存。
- “渐变宽度”控制红蓝交界的横向渐变范围，默认 80 px，可设 0–4096 实际屏幕像素。宽度不受屏幕缩放倍率影响；0 表示直接分界。进度为零时全蓝，达到终点时全红。
- 暂停时保留当前分界；无有效时长或零进度时整条为未播放颜色，进度到终点时整条为已播放颜色。屏幕分辨率、缩放及主屏幕变化后重新定位。

实现：`src/progressbar.cpp`，使用 Qt 原生透明置顶窗口与矢量渐变，无外部图片资源。

验证：使用真实 FLAC 的播放器进度检查全宽显示、红蓝分区、纵向 alpha 渐变、零进度全蓝、颜色与高度即时调整、设置持久值、主屏顶端几何，以及无子控件、无焦点、输入穿透和不接受拖放。

结果见 `top-progress-test-results.txt`，截图见 `screenshots/top-progress-red-blue.png`、`screenshots/top-progress-custom.png`、`screenshots/top-progress-settings.png`。
