# BiliWave 1.12.0 · 简装版与加装版

两版都有搜索、本地音轨下载、URL 保存、乐库、歌单、播放、工作台和桌面歌词。

| 功能 | 简装版（Lite） | 加装版 |
| --- | --- | --- |
| 本地歌曲、URL 歌曲在线匹配现成歌词 | 支持 | 支持 |
| 歌名、歌手、歌词草稿独立保存 | 支持 | 支持 |
| 导入乐库或保存时写回歌曲 | 支持 | 支持 |
| 同源视频屏幕字幕识别、GPU OCR | 不含 | 支持 |
| 音频听写、音频配时模型 | 不含 | 不含 |

URL 歌曲可从乐库右击“载入工作台”，简装版也可以直接从歌曲源选择。试听时联网解析音轨，保存配置时仍保留 URL，不强制下载。

工作台使用按歌曲 ID 分开的持久草稿。应用队列结果只替换该歌曲草稿的歌词，不用候选歌名/歌手覆盖已填写的资料；切换歌曲、后台任务完成、重复应用不会串改。乐库播放和导出仍使用已保存版本，工作台试听使用草稿。点击“保存”或“导入乐库”才一并提交元数据、歌词及偏移。

加装版发布目录为 `release-screen`，只打包 OCR 依赖和中英/俄语/意大利语 OCR 模型，不打包 PyTorch、Whisper 或 `small.pt`。旧 `release` 目录属于历史完整运行环境，不再作为当前安装包来源。

以下为简装版详细说明。

保留音乐搜索、原始音轨下载、本地导入、URL 收藏、乐库、歌单、播放队列、顶部进度条、桌面歌词、自动消声、托盘和开机启动。

搜索下载完成和 URL 收录先进入“收录队列”，可直接收录，也可载入工作台配置歌词；导入成功后清空当前工作台。直接导入本地文件仍可直接入库。保留工作台：从歌曲源选择本地或 URL 歌曲，或右击乐库歌曲选择“载入工作台”，在线搜索现成歌词，预览候选并采用已有时间轴，试听和调整整首同步偏移。支持搜索关键词或 LRCLIB 歌词链接。

所有在线歌词版本同时进入右侧识别队列，显示来源、来源记录号和队列编号，可双击查看、应用。通用设置中的“繁体中文自动转简体”默认勾选，对已有歌词和新结果即时生效，关闭后可重新查看保留的原文。

不提供字幕识别、模型对齐、TXT/LRC 歌词导入、手动逐行编辑以及本机识别任务队列。只有纯文本、没有现成时间轴的候选可查看，但不能生成配时；需选择另一个已有时间轴的版本，或使用加装版识别同源视频字幕。不会自动读取本地音频旁的 LRC。

在线搜索可清理视频标题中的音质标签，区分《明日方舟》EP 标题与真实歌名，按歌名、歌手和时长评分。支持塞壬官方、网易云音乐、QQ 音乐、LRCLIB、酷狗歌词和 Lyrics.ovh（纯文本）等选项。选择优先源和备用源后逐个查询，命中即停；每批最多 5 个结果，点击“继续搜索”取下一批。来源设置和请求限制见 [在线歌词源](ONLINE_LYRIC_SOURCES.md)。

此包不包含 Python、PyTorch、OCR、对齐模型和歌词 worker，不需要下载模型。保留 Qt、FFmpeg、ffprobe、yt-dlp 及其运行库。网络歌词只发送歌曲元数据或检索关键词，不上传音频。

默认安装到当前用户目录 Programs/BiliWave Lite，与加装版分开。卸载保留歌曲和资料库。

```powershell
./scripts/build-lite.ps1
./scripts/package-installer.ps1 -Lite
```

CMake：简装版 `BILI_ENABLE_LYRICS=ON`、`BILI_ENABLE_RECOGNITION=OFF`；加装版两项均为 `ON`。两版均使用 `BILI_ENABLE_ALIGNMENT=OFF`。
