# BiliWave Lite 1.10.0 · 在线歌词版

保留音乐搜索、原始音轨下载、本地导入、URL 收藏、乐库、歌单、播放队列、顶部进度条、桌面歌词、自动消声、托盘和开机启动。

下载完成直接进入乐库，不需要先配置歌词。保留工作台：从歌曲源选择本地歌曲，或右击乐库歌曲选择“载入工作台”，在线搜索现成歌词，预览候选并采用已有时间轴，试听和调整整首同步偏移。支持搜索关键词或 LRCLIB 歌词链接。

不提供字幕识别、模型对齐、TXT/LRC 歌词导入、手动逐行编辑以及本机识别任务队列。只有纯文本、没有现成时间轴的候选可查看，但不能生成配时；需选择另一个已有时间轴的版本，或使用完整版。不会自动读取本地音频旁的 LRC。

在线搜索可清理视频标题中的音质标签并提取《歌名》，依次尝试精确匹配、歌名加歌手、仅歌名和关键词查询，合并去重后按歌名、歌手和时长评分排序。重复点击线上匹配可查看后续候选；在搜索框按 Enter 重新检索。歌词覆盖取决于 LRCLIB 数据库。

此包不包含 Python、PyTorch、OCR、对齐模型和歌词 worker，不需要下载模型。保留 Qt、FFmpeg、ffprobe、yt-dlp 及其运行库。网络歌词只发送歌曲元数据或检索关键词，不上传音频。

默认安装到当前用户目录 Programs/BiliWave Lite，与完整版分开。卸载保留歌曲和资料库。

```powershell
./scripts/build-lite.ps1
./scripts/package-installer.ps1 -Lite
```

CMake：BILI_ENABLE_LYRICS=ON、BILI_ENABLE_RECOGNITION=OFF。完整版两项均为 ON。
