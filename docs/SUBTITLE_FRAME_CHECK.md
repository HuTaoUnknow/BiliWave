# 字幕字间距敏感度与当前帧校验（2026-10-25）

字幕语言下面的参数改为“空格间距敏感度”，默认 50%，范围 0–100%。越高越容易把较小的异常字间距识别为空格；越低要求更大的间隔。0% 是最低敏感度，不表示关闭所有空格。

## 几何判定

1. 对已检测文字框提取前景，自动选择亮字/暗字极性，按连通区域面积去除孤立噪点。不做会擦掉横细笔画的开运算或腐蚀。
2. 计算纵向投影，得到有笔画的横向区段以及相邻区段之间的空白长度。
3. 以较小的 60% 间隔的中位数估计正常字间距 `g`，以前景覆盖高度估计本行字高 `H`。不足三个间隔时，将基准间距限制在 `0.1H` 以内，避免唯一的词间距反而成为正常字距。
4. 令界面值除以 100 为 `s`，使用 `T=max(2, g*(3.5-2s), H*(0.42-0.26s))`。空隙严格大于 `T` 才分开。默认 50% 对应 `max(2, 2.5g, 0.29H)`；同字号下提高敏感度会降低阈值。
5. 按确认的长空隙切分成词块，批量交给原识别模型。可靠前景下，以测得的词块边界生成空格，不再把模型空格分数放大，也不采用词典猜词。前景不可靠时保留模型原有结果。
6. 多个检测框之间使用相同的字号归一化规则拼接，邻近的中文单字框不会再一律插入空格。双语仍保留外语一行、中文一行。

模型原始置信度不增加，几何插入的分隔不冒充模型置信度。文字框仍须通过 0.55 的过滤。分段合并继续使用原有 60% 相似度和中间片段选择规则。

## 横细笔画“一”

在本机样本中，20px 和 32px 的单独“一”未被文字框检测器返回。新增补检先寻找未被现有文字框覆盖的独立短横笔画，再给同一笔画补上下留白、对小字号放大，用中文模型检查三种比例。至少两种结果为“一”、且最高原始置信度达到 0.70 时才补回。二/三的相邻横笔画、长图形横条及已被文字框覆盖的区域会被排除，英文单语不启用中文补检。

对已含汉字的词块，还会在检测到独立横细笔画时进行有限的对比复识别。只有与原结果相比仅恢复“一”、或图像支持的独立短横被中文模型核实为“一”时，才采用修正。长破折号与连写“一一”可能外观相同，不能保证仅凭图像消除歧义。

## 设置与兼容

新设置键为 `lyrics/ocrGapSensitivity`，任务字段为 `ocr_gap_sensitivity`（0–1）。旧“空格出现概率”与新参数含义不同，因此新参数独立默认 50%，不会把原来的 100% 直接继承过来。旧参数键保留；已经提交且明确带旧字段的任务继续用旧解码方式。

正式字幕识别和“识别当前框选内容”使用同一套字距与细笔画处理，包括双语识别器。当前帧结果附带实测间隔、正常间距、判定阈值、空格数量及细笔画补检信息，便于复核。

当前帧校验仍只使用已经获取的原始帧和当前框选范围，最多缩到 1280 像素宽，不请求视频、不扫描其他帧、不生成时间轴、不写入歌曲。结果框保留两行高度，参数变化后清空旧结果。

## 验证与限制

- 单元验证覆盖敏感度方向、字距阈值、字号缩放、亮暗字、真实间隔分隔、文字框拼接、细笔画保留、二/三与长横条排除、中文模型复核、旧任务兼容和识别位置映射。
- 实际 CPU 字幕样本检查英、俄、意的明显词间距，以及中文“一”的单帧和视频补检；GPU 及 Qt 当前帧流程另行验证并记录结果。
- 缺乏真实词间距、字距排得均匀、描边粘连或背景复杂时，几何方法仍可能漏分或误分。中文繁简转换不参与字距判断，也不会改变歌词时间标签。

历史模型加权参数的验收保留在 `space-probability-validation.json` 和 `subtitle-frame-validation.json`，不代表新几何算法的验收结果。
