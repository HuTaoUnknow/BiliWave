# 字幕空格参数与当前帧校验（2026-10-24）

字幕识别窗口在“字幕语言”下方增加空格参数；再下一行，左侧为两行高的只读结果框，右侧为“识别当前框选内容”。超过两行的内容可以在框内滚动。

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| 空格出现概率 | 50.0% | 范围 0–100%；50% 为原模型解码，高于 50% 增加空格倾向，低于 50% 减少；0% 关闭模型输出空格 |

这里只显示一个百分比，它表示空格调节倾向，不是歌词中空格的实际占比、模型校准概率或识别准确率，100% 不会强制插入空格。设界面百分比除以 100 为 `q`，内部空格分数权重为 `20^(2*q-1)`，仅对模型原始空格概率至少为 1% 的时间步生效；低于门槛时保留原始分数。50% 权重为 1，完全使用原解码器；100% 权重为 20。0% 单独处理，将模型预测的空格替换为 CTC blank，不用次优字母替换。文本框拼接所需的结构性分隔不由这个参数控制。

置信度仍使用选中类别的原始概率，不把放大分数当成真实置信度。新参数同时作用于正式字幕识别和当前帧校验，包括双语模式的两个识别器，保存在 `lyrics/ocrSpaceProbability`，任务字段为 `ocr_space_probability`（0–1）。每个任务提交时记录当时数值，之后改变设置不会改写已提交的任务。

首次打开时，旧倍率 `w` 按 `q=0.5+0.5*log(w)/log(20)` 换算并限制到 0–100%，保留一位小数的百分比；旧默认值换算为 50%。新设置的内部最低门槛固定为 1%，旧的自定义最低门槛不参与新任务。已提交、明确包含旧倍率和旧门槛的任务继续按旧规则执行，避免被新设置覆盖。

“识别当前框选内容”保存预览控件持有的原始图像（不含绿框绘制），按点击时的归一化框选范围裁剪，最多缩至 1280 像素宽，使用与正式任务相同的 OCR、空格处理、0.55 行置信度过滤和双语组合。它不解析视频地址，不请求新画面，不扫描其他帧，不生成时间轴，不进入后台识别队列，也不写入歌曲歌词。没有预览帧时按钮禁用；执行时按钮转圈，范围及识别参数暂时禁用；新画面、语言、范围或参数变化会清除旧结果。

空白图像的结果为“当前框选区域未识别到文字”，失败会显示具体错误。调整“向后 15 s”仍按原流程获取下一张预览图，再由用户点击校验当前框选内容。

## 实际限制

本地《我的橘子酱》字幕帧的 GPU 校验表明，提高空格倾向可以增加空格，也会在俄语单词内部插入空格。该字幕字间距均匀，模型对词间空隙的预测不可靠；这个参数不能保证恢复正确俄语分词。因此默认保持 50%，不以词典或歌曲专用模板猜词。对准确分词有要求时，应提供已核对的歌词再匹配时间。

## 验证

- Python 测试覆盖新百分比的中性值、单调性、0% 行为、无效输入、旧参数兼容、原始置信度、输入张量不变、word box 兼容，以及单帧准确裁剪且禁止视频/FFmpeg 调用。
- Qt 流程测试覆盖同一已获取帧、参数传递与恢复、无队列/无歌曲写入、空白区域、结果失效及俄汉双行。
- 原有完整字幕识别、俄语/意大利语、后台队列及两套主题流程回归保留。
