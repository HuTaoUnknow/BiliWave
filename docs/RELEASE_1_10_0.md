# BiliWave 1.10.0

本次提供两个 Windows x64 安装包：

| 版本 | 歌词能力 | 下载后行为 |
|---|---|---|
| BiliWave 完整版 | 在线匹配、字幕 OCR、已有歌词配时、歌词导入 | 可直接收录或进入工作台配置 |
| BiliWave Lite 在线歌词版 | 保留工作台，只在线搜索和应用现成歌词 | 自动导入乐库，再按需在线匹配 |

Lite 不含本机识别、模型对齐、歌词导入、逐行编辑及识别队列，也不包含 Python、OCR 和语音模型。保留乐库、歌单、播放、桌面歌词、顶部进度条、自动消声、托盘及开机启动。两个版本安装目录分开。

在线歌词增加视频标题清理、多轮查询、合并去重及匹配度排序，支持关键词和 LRCLIB 歌词链接。精确接口繁忙时按服务端等待时间回退到目录搜索，429 限流会暂停；取消搜索后旧结果不再覆盖。纯文本候选在 Lite 中可查看，无法自动生成配时。

自动消声现支持三个独立条件：麦克风说话、其他应用开麦、其他应用实际发声。降低幅度 0–100%，默认 70%，总开关默认关闭。排除当前 BiliWave，静音和无声播放不触发，恢复时保留手动音量。

完整版已通过核心、导入、界面、字幕工作流、消声和在线搜索六组回归；在线版验证本地直接入库、在线时间轴应用及本机能力禁用。真实在线测试曲目获取到 49 行现成时间轴。安装验收详情见发布验证报告。

歌词是否存在、版本是否一致仍取决于在线数据库，建议试听确认。无需 API Key，在线查询不上传音频。
