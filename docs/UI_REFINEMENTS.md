# BiliWave 1.4 界面与 URL 收录

当前 1.9 的搜索双击、歌词编辑、任务清理和模型调整见 [UI_1_9.md](UI_1_9.md)。下方保留早期交付记录。

## 操作

- 搜索框、搜索和取消在标题“搜索”右侧。删除页头说明、展开分 P 按钮与默认介绍文字。下载及 URL 收录在“歌曲搜索”行右侧；翻页位于列表底部中央。
- 单击搜索结果，右侧歌曲源选中待收录项，可直接试听。下载音频进入待入库；URL 收录直接保存视频页面链接及歌曲信息。
- 歌词工作台标题右侧提供“导入乐库”和“不配置歌词导入乐库”。前者在有有效时间轴后提交，后者立即提交。匹配时显示动画转圈；未选歌曲时歌词列表留空。
- 乐库使用与播放页相同的唱片歌单卡片，可右击删除歌单。乐库筛选位于标题右侧，有确认 / 取消。歌曲列表右上排序：A~Z、time（时长）、size（本地文件大小），箭头控制正序 / 逆序。URL 的文件大小为 0。
- 左下收录 / 移出分别为 Ctrl+A、Ctrl+D；歌单返回为 Esc。快捷键在乐库表格与页面内生效，不截取顶部输入框的 Ctrl+A。
- 播放歌曲右侧 → 加入队列，队列左侧 ← 移出；不删除曲库记录。队列仍保持下一首在最下面。
- 悬浮条、桌面歌词开关放在左栏设置上方，在设置页也可同步切换。

## URL 播放

仅保存哔哩哔哩页面链接，保留分 P，不保存临时 CDN 地址和完整音频文件。每次激活歌曲通过 yt-dlp 解析当前可访问的高质量独立音轨，再经只绑定本机回环地址的随机路径转发。转发支持请求头和 Range，RAM 缓冲有上限，不向媒体目录写入音频。

在线歌词、LRC 适用于 URL 歌曲；本机听写与强制对齐需要先下载音频。无歌词入库会跳过匹配，不清除已经存在的歌词。
