# 托盘、图标与自启动（2026-10-23）

应用窗口、任务栏及托盘使用用户选中的第 5 款“柔润波带”，保留蓝色渐变和真实透明背景。1254×1254 PNG 原图保持不变；Windows ICO 导出 16、20、24、32、40、48、64、128、256 像素九个尺寸，并作为 EXE 图标资源编译。原参考图和五款方案保存在 `docs/icon-concepts/20261023/`，生成方式与提示词见该目录的 `PROMPTS.md`。

设置 → 通用设置：

- **关闭主窗口时最小化到托盘**：默认开启，点击关闭隐藏主窗口，播放、下载、识别继续；设置即时保存。取消勾选后，关闭窗口退出程序。
- **开机自启动（启动到托盘）**：默认不主动启用。勾选后向当前 Windows 用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入 `BiliWave`（Lite 版使用 `BiliWave Lite`），不需要管理员权限；取消勾选移除这一项，不修改其他启动项。设置页读取实际注册状态。

启动命令使用完整程序路径、`--startup` 及显式 `--data` 资料库路径，路径带空格时正确引号包围。登录后恢复原队列和播放位置，保持暂停，主窗口隐藏在托盘。没有系统托盘时显示主窗口；普通关闭会正常退出，避免留下无法打开的隐藏程序。

托盘单击或双击显示主窗口，保留最大化状态。右键菜单提供：显示主窗口、播放 / 暂停、设置、退出。退出会保存会话、取消正在进行的服务并关闭悬浮窗口。Windows 结束会话时不拦截关闭为隐藏。

同一版本类型（完整版或精简版）、相同资料库通过仅当前用户可访问的本地通信管道保持单实例；再次普通启动唤回已有窗口，搜索或导入参数转交已有实例。重复的 `--startup` 不弹出已有窗口。不同资料库可分别启动。捕获和冒烟等独立诊断流程使用原有隔离方式并显式退出。

## 验证范围

`tests/redesign_tests.cpp` 覆盖关闭到托盘后音乐继续、后台歌词任务完成但不自动应用、暂停 / 继续、恢复最大化窗口、设置入口及显式退出，检查会话保存与设置恢复。启动项的写入、关闭及不影响其他条目通过临时 INI 后端验证，不为测试修改真实 Windows 启动项。单实例通信在有独立事件循环的服务端验证。实际登录自启动未通过重启 Windows 进行测试。

`scripts/verify-desktop-startup.py` 进一步对完整版、Debug、精简版的独立 EXE 验证 `--startup` 常驻、重复自启动和普通启动转交到原进程。只创建并结束脚本自己的临时资料库测试进程，不查找或关闭用户已运行的程序。

设置与菜单截图：`docs/screenshots/tray-startup-settings.png`、`tray-menu.png`。程序版本及启动验证见 `tray-startup-validation.json`。
