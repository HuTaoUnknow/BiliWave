# BiliWave 1.3 乐库与播放页

左侧导航顺序：搜索、乐库、播放；设置仍位于底部。

- 乐库保留音乐导入、重命名、删除、歌单收录与排序管理，移除页面内直接播放入口。
- 播放页左上歌曲 / 歌单按钮互斥，歌曲与歌单详情统一显示歌名和时长。
- 歌单卡片使用原生矢量绘制方形唱片与右上方唱臂，名字在下方；单击进入、返回恢复卡片。
- 右侧播放队列由下向上堆叠，下一首在最下方，显示名字与时长。随机模式预先确定顺序，显示与实际下一首一致。
- 支持歌曲 / 歌单拖入队列、追加、跳播、移除与清空；不修改乐库记录及歌单关联。
- 旧设置页面索引自动迁移，原有资料库、歌词及播放配置继续使用。

验证：四组 CTest 通过。核心测试新增实际待播顺序、随机预告一致性、队列编辑不删除音乐；界面测试覆盖四页导航迁移、互斥按钮、单击歌单进入 / 返回、底部优先队列与歌单拖入。
